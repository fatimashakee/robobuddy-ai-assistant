# 🤖 RoboBuddy - AI Assistant Explained for Kids!

A cheerful, colorful, and interactive educational website explaining what an **AI Assistant** is in a way that even a 5-year-old can easily understand and enjoy!

---

## 🌟 Key Features

1. **🤖 Interactive Animated Mascot (RoboBuddy)**
   - Blinking eyes, pulsing antenna, and customizable expressions.
   - Click/tickle the robot to hear funny sound effects and cute messages!

2. **✨ The 3 Magic Steps of AI**
   - **Step 1:** You ask / whisper a question.
   - **Step 2:** Fast robot brain searches its giant library.
   - **Step 3:** Friendly answer arrives like a present!

3. **💬 Interactive Chat Toy**
   - Try asking questions (dinos, stars, songs, jokes, why is the sky blue).
   - Built-in cute synthesizer audio and optional Speech-to-Text reading aloud.

4. **📖 Pick & Mix Magic Story Maker**
   - Pick a Hero (Space Bunny, Dancing Dino, Superhero Pup, Flying Kitty).
   - Pick a World (Marshmallow Clouds, Glitter Ocean, Candy Planet, Treehouse Forest).
   - Pick a Superpower (Giggle Sparkles, Rainbow Laser, Bubble Shields, Cookie Baker).
   - Generates an instant bedtime story with a "Read to Me" button!

5. **🎯 Pop Quiz Game ("Can AI Do This?")**
   - Teaches healthy boundaries and truths about AI (AI has no tummy, AI can make mistakes, real hugs and family are #1).
   - Collect all 4 golden stars to win the Junior Explorer Trophy!

---

## 🚀 How to Run

1. Open [`index.html`](index.html) directly in any modern web browser (Chrome, Edge, Firefox, Safari).
2. Or run a lightweight local web server:
   ```bash
   npx serve .
   # or
   python -m http.server 3000
   ```
